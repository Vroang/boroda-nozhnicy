# Лендинг барбершопа «Борода и Ножницы» (демо)

**Сайт:** https://vroang.github.io/boroda-nozhnicy/
**Бот записи:** [@boroda_nozhnicy_demo_bot](https://t.me/boroda_nozhnicy_demo_bot?start=site)

Демо для портфолио — связка «сайт + Telegram-бот». Барбершоп вымышленный.
Все кнопки «Записаться» ведут в бота. Форм и сбора данных на сайте нет.

Чистый HTML + CSS + немного JS, без фреймворков и внешних запросов:
шрифты лежат локально, вместо виджета карты — SVG-схема.

## Как открыть у себя

Из папки сайта запустить локальный сервер:

```
python -m http.server 8765
```

и открыть http://localhost:8765 (остановить — `Ctrl+C`). Можно и просто открыть `index.html` двойным кликом.

## Как обновить сайт на GitHub Pages

1. Поправить файлы.
2. Запустить **`deploy.bat`** (двойной клик). Он покажет изменения, сделает коммит и отправит на GitHub.
3. Через 1–2 минуты сайт обновится. GitHub Pages разрешает браузерам кэшировать файлы до 10 минут,
   поэтому если видна старая версия — обновить страницу с `Ctrl+F5` (на телефоне — подождать или открыть в новой вкладке).

При первом запуске на новом компьютере Git Credential Manager откроет вход в GitHub через браузер —
пароль и токены вводить в консоль не нужно.

Что попадает на сайт, решает `.gitignore` (белый список): только `index.html`, `css/`, `js/`, `fonts/`,
картинки `img/*.webp`, `img/*.jpg` и иконки. Исходные PNG, ТЗ, заметки и скрипты остаются локально.
Новый тип файла (например, `.svg`) нужно добавить в `.gitignore` строкой `!img/*.svg`, иначе он не уйдёт на сайт.

## Структура

```
index.html            — вся страница (11 блоков: шапка … подвал)
css/style.css         — стили, mobile-first; цвета в :root
js/main.js            — бургер, вкладки услуг, галерея, плавающая кнопка, анимации
fonts/                — Oswald (заголовки) и Manrope (текст), woff2: кириллица, латиница и знак ₽
img/                  — *.webp + запасные *.jpg, og.jpg (превью ссылки), иконки
favicon.ico, site.webmanifest
deploy.bat            — публикация на GitHub Pages
```

## Данные барбершопа

Перенесены вручную из `config.py` Telegram-бота. Если в боте меняются данные — поправить в `index.html`:

| В config.py бота | Где на сайте |
|---|---|
| `CATEGORIES` (услуги, длительность, цены) | блок `#services`, каждая услуга — `<li class="svc">` |
| `MASTERS` (имя, уровень, about, work_days) | блок `#masters`, `<article class="master">` |
| `FIRST_VISIT_DISCOUNT`, `BONUS_PERCENT` | блоки `#promo`, `#why`, первый экран |
| `FAQ` | блок `#faq`, `<details>` |
| `ADDRESS`, `PHONE`, `WORK_START/END`, `MAP_URL` | первый экран, `#contacts`, JSON-LD в `<head>` |

Если у услуги цены у обоих уровней одинаковые — одна ячейка `svc__price--single` («у любого мастера»).

## Картинки

Исходники PNG (из нейросети) хранятся локально и в репозиторий не попадают.
Пересборка всех картинок (WebP + JPG до ~200 КБ, og.jpg, favicon, эмблема) — локальным скриптом
`tools/build_images.py` (нужен Pillow, ставить во временный venv):

```
python -m venv %TEMP%\imgvenv
%TEMP%\imgvenv\Scripts\pip install pillow
%TEMP%\imgvenv\Scripts\python tools\build_images.py . %TEMP%\bot-img
```

## Адрес сайта

Адрес прописан в `<head>` (`og:url`, `og:image` — для превью ссылки в Telegram) и в `deploy.bat` (`SITE`).
При переезде на другой адрес (например, домен заказчика) поменять в обоих местах.
